# Car-black-box
The Car Black Box project using a PIC18F4580 microcontroller is designed to log and store critical operational data of a vehicle, such as speed, gear position, and the exact time of various events. This data is crucial for post-incident analysis, offering insights into driver behavior or possible malfunctions. The system features a secure, password-protected menu interface that allows users to view logs, download data, set or update the system clock, and change the password. Communication with peripherals like the Real-Time Clock (RTC) and external EEPROM is handled using UART and I2C protocols. One of the key challenges encountered was navigating and displaying logs efficiently. To address this, bit manipulation techniques were employed for efficient access to time registers and secure password management. This project showcases the practical integration of communication protocols, embedded memory management, and security within an embedded automotive application.
